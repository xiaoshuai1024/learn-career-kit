# SPEC — Learn Career Kit（个人学习 + 职业决策知识库）

> 版本：v0.1（2026-08-14）

## 1. 定位

一套**可复用的个人学习与职业决策知识库框架**，配合 AI 编码助手（Claude Code / Codex / ZCode 等）形成闭环：

```
能力评估（量化当前水平）
    ↓
岗位目标（目标岗位能力权重）
    ↓
差距分析（薄弱项排序）
    ↓
系统学习（/study 教材 + 检测 + 模拟面试）
    ↓
知识沉淀（生词本 / 错题本 / 学习记录）
    ↓
再评估（快照追加油趋势）→ 循环
```

## 2. 核心组成

| 模块 | 文件/目录 | 说明 |
|------|-----------|------|
| 能力评估数据 | `docs/能力评估数据.json` | **唯一真相源**：6 维度 / 126 技能 / 岗位目标权重 / snapshots 历史快照 |
| 报告生成 | `scripts/gen-skill-report.mjs` | JSON → 评分表 md + ECharts 雷达图 html + 趋势 csv |
| 差距分析 | `scripts/job-gap-report.mjs`、`scripts/gen-job-gap.mjs` | 岗位要求 vs 当前能力 → 差距矩阵 |
| 学习命令 | `.claude/commands/study.md`、`skill-test.md` | `/study` 系统化学习、`/skill-test` 技能测评（AI 助手斜杠命令） |
| 知识沉淀 | `docs/templates/` | 生词本 / 错题本 / 学习记录 / 每日日志的体例模板与示例 |
| 知识教材 | `docs/*.md` | 岗位能力图谱、前后端架构师图谱、系统设计/八股/微服务面试教材 |
| 转换工具 | `scripts/md2pdf*.mjs`、`pdf2md.py`、`marked-wrapper.mjs` | Markdown ↔ PDF 工具链 |

## 3. 数据流

```
能力评估数据.json（唯一真相源，snapshots 数组追加式）
        │
        ├── node scripts/gen-skill-report.mjs
        │       ├── docs/个人能力评分表.md（脚本生成，勿手改）
        │       ├── docs/能力评估报告.html（雷达图+趋势）
        │       └── docs/能力评估趋势.csv
        │
        └── node scripts/job-gap-report.mjs
                └── 终端差距矩阵（岗位要求分 vs 当前分）

/study    ──► snapshots + 学习记录 + 每日日志 + 技术学习清单 + 错题本 + 生词本
/skill-test ──► snapshots + 错题本
```

## 4. 文档职责矩阵（唯一写入地）

| 内容类型 | 唯一写入地 | 说明 |
|----------|------------|------|
| 错题（答错/不完整） | `docs/错题本.md` | 其他文档只引用「详见错题本 X 类」 |
| 已学主题档案 | `docs/学习记录.md` | 一个主题一条，禁止内联完整错题 |
| 会话过程流水 | `docs/每日学习日志.md` | 测验分数、面试评价、评分变更 |
| 待办/缺口 | `docs/技术学习清单.md` | 唯一待办池，状态迁移 |
| 评分数字 | `docs/能力评估数据.json` | 唯一真相源，报告全是脚本转写 |

## 5. 范围（in / out）

**包含**：能力评估体系、学习命令、知识沉淀模板、面试教材、MD/PDF 工具链。
**不包含**：招聘平台爬虫、自动投递工具、任何真实个人信息（仓库内数据均为虚构示例人物「张三」）。

## 6. 评分体系

- 档位：0 待评估 / 20 不了解 / 40 了解概念 / 60 能使用 / 80 熟练掌握 / 100 精通
- 达标线：pass = 60%，compete = 80%
- 从严评分原则：自评略低于真实水平，留安全边际
- 岗位要求按维度满分**百分比**存储，满分变化自动重算
