# 后端/架构师缩写速查表

> **用途**：教材/面试题中所有缩写的**全拼 + 中文 + 常见别名 + 一句话解释**。学习遇到不熟悉的缩写随时查。
> **使用**：按字母排序，每条格式 = `缩写（全拼，中文，别名）— 一句话`。
> **联动**：每次学习新出现的缩写追加到本表。

---

## A

- **ACID**（Atomicity, Consistency, Isolation, Durability，原子性/一致性/隔离性/持久性）— 数据库事务四大特性。
- **AOP**（Aspect-Oriented Programming，面向切面编程）— 把日志/事务等横切逻辑抽出来统一处理。Spring 底层用动态代理实现。
- **AP**（Availability & Partition tolerance，可用性+分区容错）— CAP 中选可用性的方案（如 Nacos/Eureka/Redis），允许短暂不一致。
- **API**（Application Programming Interface，应用程序编程接口）— 软件间交互的约定。
- **APM**（Application Performance Monitoring，应用性能监控）— 监控应用性能（如 SkyWalking/Pinpoint）。
- **ACK**（Acknowledgment，确认应答）— 接收方收到消息后回的确认。MQ 中消费完才 ACK（防丢）。
- **ADR**（Architecture Decision Record，架构决策记录）— 记录架构决策的文档（背景+决策+后果）。
- **AT**（Auto Transaction，自动事务）— Seata 的一种模式，自动生成 undo_log 回滚，业务无侵入。
- **AOF**（Append Only File，追加日志文件）— Redis 持久化方式之一，记录所有写命令。
- **AVL**（Adelson-Velsky and Landis，人名）— AVL 自平衡二叉搜索树（严格平衡）。
- **ACL**（Anti-Corruption Layer，防腐层）— DDD 集成模式，隔离外部/老系统的烂模型。
- **APISIX**（Apache API SIX，API 网关开源项目）— 基于 OpenResty 的云原生 API 网关。

## B

- **B+树**（B+ Tree，多路平衡搜索树）— MySQL 索引底层结构，数据全在叶子节点。
- **BASE**（Basically Available, Soft state, Eventually consistent，基本可用/软状态/最终一致）— CAP 选 AP 后的工程实践理论。
- **BGSAVE**（Background Save，后台保存）— Redis RDB 持久化命令，fork 子进程做快照。
- **BIO**（Blocking I/O，阻塞 IO）— 传统 Java IO，一个连接一个线程。
- **BFF**（Backend For Frontend，服务于前端的后端）— 介于前端和后端之间的聚合层。

## C

- **CAP**（Consistency, Availability, Partition tolerance，一致性/可用性/分区容错）— 分布式系统三者不可兼得定理。
- **CAS**（Compare-And-Swap，比较并交换）— 原子操作，CPU 指令（cmpxchg）保证。乐观锁基础。
- **CDN**（Content Delivery Network，内容分发网络）— 静态资源就近返回，减轻源站压力。
- **CGLIB**（Code Generation Library，代码生成库）— Spring AOP 的代理方式之一（基于继承生成子类）。
- **CLH**（Craig, Landin, Hagersten，三人姓氏）— AQS 等待队列的链表结构（双向）。
- **CP**（Consistency & Partition tolerance，一致性+分区容错）— CAP 中选一致性的方案（如 ZooKeeper/MySQL 半同步），强一致但牺牲部分可用性。
- **CRC**（Cyclic Redundancy Check，循环冗余校验）— 一种哈希算法，Redis Cluster 用 CRC16 算 slot。
- **CRUD**（Create, Read, Update, Delete，增删改查）— 数据库四种基本操作。
- **CQRS**（Command Query Responsibility Segregation，命令查询职责分离）— 读写分离的架构模式。
- **CMS**（Concurrent Mark Sweep，并发标记清除）— 老年代垃圾回收器，已弃用。
- **CI/CD**（Continuous Integration / Continuous Delivery，持续集成/持续交付）— 自动化构建测试部署。
- **CPU**（Central Processing Unit，中央处理器）— 计算机的"大脑"。
- **COW**（Copy-On-Write，写时复制）— fork 时父子共享内存，写时才复制。
- **C10K**（Client 10K，1 万客户端）— 单机处理 1 万并发连接的问题。

## D

- **DCL**（Double-Checked Locking，双重检查锁定）— 单例模式的延迟初始化写法，必须 volatile（防指令重排）。
- **DDD**（Domain-Driven Design，领域驱动设计）— 让代码结构贴合业务领域的方法论。
- **DI**（Dependency Injection，依赖注入）— IoC 的实现方式，容器主动注入依赖。
- **DLQ**（Dead Letter Queue，死信队列，又叫死信/隔离队列）— 消费失败重试 N 次后进的队列，避免阻塞主流程。
- **DNS**（Domain Name System，域名系统）— 域名解析到 IP。
- **DTO**（Data Transfer Object，数据传输对象）— 跨层传输数据的对象。
- **DORA**（DevOps Research and Assessment，DevOps 研究评估）— DevOps 四指标（部署频率/变更前置时间/故障恢复时间/故障率）。
- **DLedger**（Distributed Ledger，分布式日志）— RocketMQ 的 raft 实现。

## E

- **ES**（Elasticsearch，弹性搜索，又叫 ES）— 分布式搜索/分析引擎，基于 Lucene。
- **ETL**（Extract, Transform, Load，抽取/转换/加载）— 数据仓库清洗流程。

## F

- **FIFO**（First In First Out，先进先出）— 队列规则。
- **Flink**（Apache Flink，流处理框架）— 实时流计算引擎。

## G

- **GC**（Garbage Collection，垃圾回收）— JVM 自动回收内存机制。
- **gRPC**（gRPC Remote Procedure Calls，gRPC 远程过程调用）— Google 的 RPC 框架，基于 HTTP/2 + protobuf。
- **GMT**（Greenwich Mean Time，格林尼治标准时间）— 时区基准。

## H

- **HB**（Happens-Before，先行发生）— JMM 的偏序关系，A hb B 则 A 对 B 可见。
- **HDR**（High Dynamic Range Histogram，高动态范围直方图）— 用于精确测量延迟分位数（如 TP99）。
- **HPA**（Horizontal Pod Autoscaler，Pod 水平自动扩缩容）— K8s 根据指标自动扩缩 Pod。
- **HTTP**（HyperText Transfer Protocol，超文本传输协议）— Web 通信协议。

## I

- **ICP**（Incremental Condition Pushdown，索引条件下推）— MySQL 5.6+ 优化，减少回表。
- **IoC**（Inversion of Control，控制反转）— 对象创建由容器管，不是类自己 new。
- **IOPS**（Input/Output Operations Per Second，每秒 IO 操作数）— 磁盘性能指标。
- **IP**（Internet Protocol，互联网协议）— 网络层协议。
- **ISR**（In-Sync Replicas，同步副本集）— Kafka 中和 leader 保持同步的副本。
- **IDE**（Integrated Development Environment，集成开发环境）— 如 IntelliJ IDEA。

## J

- **JIT**（Just-In-Time Compilation，即时编译）— JVM 运行时把热点代码编译成机器码。
- **JMM**（Java Memory Model，Java 内存模型）— 规范多线程下内存访问（可见性/原子性/有序性）。
- **JSON**（JavaScript Object Notation，JS 对象表示法）— 轻量数据格式。
- **JUC**（Java Util Concurrent，Java 并发包）— java.util.concurrent 包。
- **JVM**（Java Virtual Machine，Java 虚拟机）— Java 运行时。

## K

- **K8s**（Kubernetes，源自希腊语"舵手"，K+S=Kubernetes 简写）— 容器编排平台。
- **KPI**（Key Performance Indicator，关键绩效指标）— 业务核心衡量指标。
- **KVC**（Key-Value Coding，键值编码）— Apple 框架概念。
- **Kafka**（Apache Kafka，作者 Franz Kafka 姓氏）— 高吞吐消息队列。

## L

- **LB**（Load Balancer/Balancing，负载均衡器/负载均衡）— 分发流量到多台机器。
- **LRU**（Least Recently Used，最近最少使用）— 缓存淘汰算法。
- **LSN**（Log Sequence Number，日志序列号）— MySQL/PG 中日志位置标识。
- **LTS**（Long Term Support，长期支持版本）— 软件稳定版本。
- **LIFO**（Last In First Out，后进先出）— 栈规则。

## M

- **MHA**（Master High Availability，主库高可用）— MySQL 自动故障转移工具。
- **MQ**（Message Queue，消息队列）— 异步通信中间件。
- **MTBF**（Mean Time Between Failures，平均故障间隔时间）— 可用性指标。
- **MTTR**（Mean Time To Repair/Recover，平均恢复时间）— 可用性指标。
- **MGR**（MySQL Group Replication，MySQL 组复制）— MySQL 多节点强一致方案。
- **MVC**（Model-View-Controller，模型-视图-控制器）— 经典架构模式。
- **MQA**（Memory Query Analyzer）— Java 内存分析工具（少见）。
- **MAT**（Memory Analyzer Tool，内存分析工具）— Eclipse 出品，分析 heap dump。

## N

- **NIO**（Non-blocking I/O / New I/O，非阻塞 IO）— Java 1.4+ 的多路复用 IO。
- **NPE**（NullPointerException，空指针异常）— Java 最常见运行时异常。
- **NoSQL**（Not Only SQL，非关系型数据库）— 如 Redis/MongoDB/ES。

## O

- **OOM**（OutOfMemoryError，内存溢出错误）— JVM 内存不够抛的错。
- **OLAP**（Online Analytical Processing，联机分析处理）— 数据分析场景（如 ClickHouse）。
- **OLTP**（Online Transaction Processing，联机事务处理）— 日常业务场景（如 MySQL）。
- **ODS**（Operational Data Store，操作数据层）— 数仓最底层（原始数据）。
- **ORM**（Object-Relational Mapping，对象关系映射）— 如 MyBatis/Hibernate。

## P

- **PC**（Producer-Consumer，生产者-消费者）— 经典并发模式。
- **PCB**（Printed Circuit Board，印刷电路板）— 硬件术语。
- **PID**（Process Identifier / Product ID，进程 ID / 商品 ID）— 看上下文。
- **Paxos**（希腊岛屿 Paxos，作者 Lamport 起名）— 分布式一致性算法（理论经典）。
- **QPS / TPS**：见 Q/T。
- **Pod**（K8s 最小调度单位，一组成员）— K8s 中一组容器的集合。
- **Protocol**（协议）— 通信规则。

## Q

- **QPS**（Queries Per Second，每秒查询数）— 服务吞吐量指标。
- **QPS / RT / 并发数关系**：并发数 = QPS × RT（Little's Law，利特尔法则）。

## R

- **RBAC**（Role-Based Access Control，基于角色的访问控制）— 权限模型。
- **RDB**（Redis DataBase，Redis 数据快照）— Redis 持久化方式之一（全量快照）。
- **REST**（Representational State Transfer，表述性状态转移）— 一种 HTTP API 风格。
- **RMI**（Remote Method Invocation，远程方法调用）— Java 原生 RPC。
- **RPC**（Remote Procedure Call，远程过程调用）— 调远程像调本地。代表 Dubbo。
- **RT**（Response Time，响应时间）— 请求从发到收到响应的时间。
- **RTU**（Remote Terminal Unit，远程终端单元）— 工控设备（非互联网常用）。
- **RU**（Read Uncommitted，读未提交）— SQL 隔离级别最低档。
- **RC**（Read Committed，读已提交）— SQL 隔离级别（Oracle 默认）。
- **RR**（Repeatable Read，可重复读）— SQL 隔离级别（MySQL 默认）。
- **Raft**（作者 Ongaro 起名 Raft"木筏"，paxos 的工程化）— 易懂的分布式一致性算法。
- **Redis**（Remote Dictionary Server，远程字典服务器）— 内存 KV 数据库。
- **RPM**（Requests Per Minute，每分钟请求数）— AI 接口常用限流指标。
- **RPO**（Recovery Point Objective，恢复点目标）— 灾备可容忍数据丢失量。
- **RTO**（Recovery Time Objective，恢复时间目标）— 灾备可容忍停机时间。

## S

- **SaaS**（Software as a Service，软件即服务）— 软件交付模式。
- **SDS**（Simple Dynamic String，简单动态字符串）— Redis String 底层实现。
- **SLA**（Service Level Agreement，服务等级协议）— 对客户的承诺（如 99.99% 可用）。
- **SLI**（Service Level Indicator，服务等级指标）— 具体测量值（如成功率/TP99）。
- **SLO**（Service Level Objective，服务等级目标）— 内部目标（如 SLA 99.99% 内部 SLO 99.95% 留余量）。
- **SOP**（Standard Operating Procedure，标准操作流程）— 应急/运维标准流程。
- **SPI**（Service Provider Interface，服务提供者接口）— 面向接口编程，运行时加载实现。Dubbo 核心扩展机制。
- **SQL**（Structured Query Language，结构化查询语言）— 数据库查询语言。
- **SSD**（Solid State Drive，固态硬盘）— 比机械盘快百倍。
- **SSR**（Server-Side Rendering，服务端渲染）— 在服务端生成 HTML。
- **STW**（Stop The World，暂停所有应用线程）— GC 时暂停，是卡顿元凶。
- **Saga**（源自冰岛语"故事"）— 长事务切短事务+补偿的分布式事务模式。
- **Sentinel**（"哨兵"，阿里开源）— 限流熔断降级组件。
- **ShardingSphere**（Apache ShardingSphere，分片球/分片领域）— 分库分表中间件。
- **SkyWalking**（"天空漫步"，Apache 项目）— APM/链路追踪工具。
- **SLF4J**（Simple Logging Facade for Java，简单日志门面）— Java 日志接口。
- **SOA**（Service-Oriented Architecture，面向服务架构）— 微服务的前身。
- **SDLC**（Software Development Life Cycle，软件开发生命周期）— 需求/设计/编码/测试/部署。
- **SPI**（Serial Peripheral Interface，串行外设接口）— 硬件通信协议（注意：和 Java SPI 同名不同义，看上下文）。
- **SLO**（Service Level Objective）— 见上。
- **Sync**（Synchronization，同步）— 多线程协调。
- **SYN**（Synchronize，TCP 三次握手标志位）— TCP 建立连接。

## T

- **TC/TM/RM**（Transaction Coordinator / Transaction Manager / Resource Manager，事务协调者/事务管理器/资源管理器）— Seata 三角色。
- **TCC**（Try-Confirm-Cancel，尝试-确认-取消）— 业务层两阶段分布式事务方案。
- **TCP**（Transmission Control Protocol，传输控制协议）— 可靠传输层协议。
- **TPS**（Transactions Per Second，每秒事务数）— 写吞吐量指标。
- **TP99**（Tail Percentile 99，99 分位数）— 99% 请求比这个值快，专盯长尾。
- **TP90/TP99.9**：类似 TP99，不同分位数。
- **TTL**（Time To Live，存活时间）— 缓存过期时间/网络跳数限制。
- **TCC**（同上）。
- **TLS**（Transport Layer Security，传输层安全协议）— HTTPS 的安全层。
- **TPS**（Transactions Per Second）— 见上。
- **TTL/RTT**（Time To Live / Round-Trip Time）— 见 TTL；RTT 是网络往返时间。
- **TDD**（Test-Driven Development，测试驱动开发）— 先写测试再写实现。
- **TLAB**（Thread Local Allocation Buffer，线程本地分配缓冲）— JVM 内存分配优化。

## U

- **URL**（Uniform Resource Locator，统一资源定位符）— 网址。
- **UTC**（Coordinated Universal Time，协调世界时）— 世界标准时间。
- **UUID**（Universally Unique Identifier，通用唯一识别符）— 128 位唯一 ID。
- **UPS**（Uninterruptible Power Supply，不间断电源）— 硬件术语。
- **UML**（Unified Modeling Language，统一建模语言）— 软件设计图。

## V

- **VM**（Virtual Machine，虚拟机）— 如 JVM/KVM。
- **VIP**（Virtual IP，虚拟 IP）— 浮动 IP（如 LVS/keepalived）。
- **VPC**（Virtual Private Cloud，私有网络）— 云上网络隔离。

## W

- **WAL**（Write-Ahead Logging，预写式日志）— 先写日志再改数据（MySQL redo log 机制）。
- **WAF**（Web Application Firewall，Web 应用防火墙）— 防 SQL 注入/XSS。
- **WS**（WebSocket）— 全双工通信协议。
- **WBS**（Work Breakdown Structure，工作分解结构）— 项目管理术语。

## X/Y/Z

- **XA**（eXtended Architecture，分布式事务规范）— X/Open 组织的分布式事务标准（基于 2PC）。
- **XML**（eXtensible Markup Language，可扩展标记语言）— 数据格式。
- **YAML**（YAML Ain't Markup Language，递归缩写）— 配置文件格式。
- **ZGC**（Z Garbage Collector，Z 垃圾回收器）— JDK 11+ 的低延迟 GC（STW < 10ms）。
- **ZK**（ZooKeeper，动物园管理员）— 分布式协调服务（Kafka/Hadoop 用）。
- **ZIP**（Zone Improvement Plan，邮政编码改进计划）— 压缩格式（最初是邮政编码）。

## 易混缩写对照

| 缩写 | 含义 | 易混点 |
|---|---|---|
| ACID vs BASE | 事务 vs 最终一致 | 一个强一致一个最终一致 |
| CAP 三性 | C/A/P | 选 P，C/A 二选一 |
| RC/RR/RU | 读已提交/可重复读/读未提交 | 都是 SQL 隔离级别 |
| RC/CP/AP | 读已提交 / 一致性+分区 / 可用性+分区 | RC 是隔离级别，CP/AP 是 CAP 选项 |
| RPC vs REST | 远程过程调用 vs 表述性状态转移 | RPC 是技术（Dubbo），REST 是风格（HTTP API） |
| SPI（Java）vs SPI（硬件） | 服务扩展点 vs 串行外设接口 | 同名不同义，看上下文 |
| TTL（缓存）vs TTL（网络） | 过期时间 vs 跳数限制 | 看上下文 |
| DLQ vs DLedger | 死信队列 vs RocketMQ raft 实现 | 都是 D 开头 |
| TC/TM/RM | Seata 三角色 | 协调者/管理器/资源 |
| TP99 vs TP99.9 | 99 分位 vs 999 分位 | 后者更严格 |

## 使用建议

- **学习遇到不熟悉的缩写**：先查本表，理解全拼+含义
- **教材首次出现缩写**：作者必须按规范 12 给全拼+中文+别名
- **新缩写出现**：追加到本表对应字母章节

> **缩写不是"显得专业"的障碍，而是行业约定的速记符号**。理解全拼才能真懂概念。
