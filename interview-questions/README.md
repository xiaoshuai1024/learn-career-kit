## 核心打法（按求职目标优先级）

> 🎯 目标：青岛/济南 ｜ 技术总监 > 架构师 > 全栈 > 前端 ｜ 优先 AI 方向

### 🏆 P0 技术总监岗（主目标，管理岗）
题型是**行为面试(STAR)/情境题**，不是技术八股。放大某头部电商6年管理实战(20+人全职能团队)+某创业项目研发产品双角色，对齐JD六大职责(技术战略/研发体系/团队管理/架构把控/跨部门/创新)。**差异化三张牌**：技术型管理者 + **AI工程化前瞻（管理×AI专项见纯管理版）** + 产品视角。管理方法论体系化要补。

**青岛 vs 济南技术总监打法差异**：
- **青岛**（海尔/海信/歌尔）：偏**产品研发**，C 端体验/高并发/营销系统是考点。放大鲁班 10万QPS + 智能家居 AI。
- **济南**（浪潮系/中创软件/山大地纬）：偏**ToB 交付 + 信创合规**。高频考点：**信创适配（达梦/人大金仓/OceanBase）、等保 2.0、招投标技术方案、多甲方需求变更管理、数据安全合规**。话术：某创业项目多租户隔离 + 审计链路 + 资金级强一致 = 与等保/合规要求相通的设计思路。

### 🏗 P1 架构师岗（架构决策）
- **后端架构师**：王牌是某创业项目分润资金链路（基点整数/状态机/锁/审计对账的资金级强一致）+ 某头部电商10万QPS高并发 + 850表Flyway治理。讲分布式架构/系统设计/高可用/资金一致性方案。
- **前端架构师**：王牌是鲁班低代码（自研渲染引擎、SSR+CDN 10万QPS、百万行Vue2→3 codemod、9子项目多端）。讲架构决策和取舍，不拼执行层八股。
- **AI 架构岗**（摸高）：放大架构优势（某头部电商6年）+ 诚实面对 AI 算法深度差距（LoRA/微调🔴），用系统设计和架构思维 + 某创业项目 RAG/Agent 工程化实战弥补。

### 💻 P1 AI 应用开发岗（核心方向）
你是「AI 落地工程师」，王牌是某创业项目 AI 助手平台（RAG+Agent+Spring AI）。**详见 [AI应用开发-全面面试题集](md/AI应用开发-全面面试题集.md)（79题）**。
- **济南特殊机会**：浪潮海若大模型、政企 AI 中台、医疗/能源 AI 是真实方向，你的 RAG/Agent/Spring AI 实战有差异化。
- **青岛**：AI 应用起步阶段，多在大企业内部孵化（海尔智能家居 AI、海信）。

### 🔧 P2 全栈 / 前端岗（保底）
- **全栈岗**：端到端独立交付 + 架构取舍是核心。王牌是某创业项目百万行 SaaS + 某头部电商 120+ 系统。
- **前端岗**：优势在真实大项目实战（鲁班低代码 10万QPS、百万行 Vue2→Vue3）。别和纯背八股的拼定义，主动往项目深挖引。

> 📍 **地域小结**：两城策略——青岛主攻家电智造应用层 + AI（海尔/海信/歌尔），济南主攻 ToB/信创 + 浪潮 AI 基础设施。技术总监是两城共同最高目标。详见 `docs/青岛研发岗位调研.md`。

## 使用建议

- **面试前 1 周**：通读目标岗位整份 + 重点过薄弱点专项。
- **每天**：背 3-5 道项目深挖题的数字和要点（数据要能拆解，别只甩结论）。
- **被问倒时**：坦诚说"这块在深入"+ 给方向，比硬装精通得分高。主动讲项目诚实边界（冲正降级、无 Grafana、74 技能是社区库等）反而是加分项。

## 生成与更新

面试题用 Markdown 写，转 PDF（精美样式）：

```bash
# 生成单份 PDF（md 在 md/，PDF 输出到 pdf/）
node scripts/md2pdf.mjs interview-questions/md/高级前端开发-面试题.md -o interview-questions/pdf/高级前端开发-面试题.pdf --style interview-questions/style.css --no-header

# 批量生成所有 PDF
for f in interview-questions/md/*.md; do
  base=$(basename "$f" .md)
  node scripts/md2pdf.mjs "$f" -o "interview-questions/pdf/$base.pdf" --style interview-questions/style.css --no-header
done
```

- 样式：`interview-questions/style.css`（学习友好排版：蓝底模块标题、绿底答案引用、深色代码块、蓝表头表格）
- 转换脚本：`scripts/md2pdf.mjs`（Puppeteer + Chrome，已修复 blockquote 渲染）
- 修改 md 后重新跑命令刷新 PDF
