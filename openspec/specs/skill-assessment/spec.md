# skill-assessment Specification

## Purpose
能力评估系统：把个人各方向技能评分以唯一真相源 JSON 管理，通过快照累积形成进步趋势，并由脚本转写出人类可读的报告产物与岗位差距矩阵。
## Requirements
### Requirement: 评分数据唯一真相源
所有技能评分数字只存在于 `docs/能力评估数据.json`；评分表（md）、可视化报告（html）、趋势（csv）均为脚本生成的转写产物，手工修改生成物无效。

#### Scenario: 追加评估快照
- **WHEN** 一次学习（`/study`）或测试（`/skill-test`）完成并向 `snapshots` 数组末尾追加一条 `{date, source, scope, scores}` 记录后运行报告脚本
- **THEN** 当前分数按该维度/技能的全部快照推导刷新，三产物（评分表 md / HTML 报告 / 趋势 CSV）同步再生成，历史快照不被覆盖

#### Scenario: 手改生成物
- **WHEN** 用户手工编辑脚本生成的评分表/HTML/CSV
- **THEN** 下次运行报告脚本时被覆盖，不影响真相源数据

### Requirement: 评分刻度与达标线
评分采用百分制离散档位 0/20/40/60/80/100（0=待评估、20=不了解、40=了解概念、60=能使用、80=熟练掌握、100=精通/能教别人），达标线为 60%，竞争线 80%；评分策略为从严评分、留安全边际。

#### Scenario: 档位判定
- **WHEN** 某技能测评出现概念混淆/根本错误类硬伤
- **THEN** 该技能评分被限制在 ≤40 档，并在 note 中记录薄弱点

### Requirement: 岗位能力差距矩阵
岗位差距脚本以悲观计分模型对比当前能力与目标岗位权重，输出各维度「当前分 / 要求分 / 差距」矩阵；岗位权重变更时可通过脚本顶部配置调整后重算。

#### Scenario: 重算差距
- **WHEN** 用户评分更新后运行 `node scripts/job-gap-report.mjs`
- **THEN** 终端输出最新差距矩阵，无文件产物被破坏

### Requirement: 报告可离线查看
HTML 可视化报告（雷达图 + 趋势折线 + 技能进度条）可离线在浏览器直接打开，不依赖外部网络服务。

#### Scenario: 离线打开
- **WHEN** 在无网络环境用浏览器打开 `docs/能力评估报告.html`
- **THEN** 图表完整渲染，数据来自内联的评估数据
