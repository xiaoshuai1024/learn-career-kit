# /skill-test 技能测试命令

你正在执行 `/skill-test` 技能测试流程。用户传入参数：`$ARGUMENTS`

## 相关文件
- 评分数据源（**唯一真相源**，测试后追加快照）：`docs/能力评估数据.json`
- 错题归档：`docs/错题本.md`（不存在则先从 `docs/templates/错题本.md` 复制）
- 评分表（脚本生成，勿手改）：`docs/个人能力评分表.md`
- 可视化报告（浏览器打开）：`docs/能力评估报告.html`
- 趋势数据（Excel 看）：`docs/能力评估趋势.csv`
- 生成脚本：`node scripts/gen-skill-report.mjs`
- 评分标准（百分制）：**0=待评估 | 20=不了解 | 40=了解概念 | 60=能使用 | 80=熟练掌握 | 100=精通/能教别人**

## 参数路由

### 模式 A：`$ARGUMENTS` 为空 —— 查看全部
1. 读取 `docs/能力评估数据.json`（或生成的 `docs/个人能力评分表.md`）
2. 输出当前各方向评分概览（当前得分 / 满分 / 达标线 60% / 竞争线 80%，并指出差距）
3. 提示用户可打开 `docs/能力评估报告.html` 看雷达图 + 进步趋势
4. 列出六大可测试方向 + 当前评分，询问用户要测哪个

### 模式 B：`$ARGUMENTS` = 方向名
方向 → 评分表章节映射：
- `前端` → "一、前端能力"全部技能（HTML/CSS/JS/TS/浏览器原理/网络/Vue/React/工程化/性能优化/小程序/AI交互层等，共 24 项）
- `后端` → "二、后端能力"（Java/Spring/MySQL/Redis/MQ/Docker/K8s 等，共 18 项）
- `AI工程化` → "三、AI工程化能力"（Spring AI/LangChain/RAG/Agent/MCP/向量库/多模型等，共 27 项）
- `全栈架构` → "四、全栈/架构能力"（分布式/微服务/DDD/全栈交付/生产级保障等，共 12 项）
- `Python` → "五、Python能力"（基础/Web/数据处理/异步/工程化，共 5 项）
- `管理` → "六、管理能力"（团队/战略/效能/领导力/管理×AI/政企ToB特色，共 20 项）

### 模式 C：`$ARGUMENTS` = 具体技能（如 "React原理"、"Vue3响应式"、"MCP协议"）
精准确位到评分表中对应技能行，只测这一项。

## 测试流程

### 第 1 步：读取目标技能
从 `docs/个人能力评分表.md` 读取要测试的技能列表及当前评分。

### 第 2 步：逐技能测试
对每个目标技能：
1. 出 2-3 道由浅入深的题（概念 → 原理 → 应用/代码）
2. 等待用户作答
3. 评分并讲解，**指出薄弱点**

### 第 3 步：汇总评分
根据作答给出每个技能的新评分（0-100 百分制）：
- 0 = 待评估
- 20 = 不了解
- 40 = 了解概念
- 60 = 能使用（独立完成常规任务，关键点需查证）
- 80 = 熟练掌握（生产级、独立排查疑难）
- 100 = 精通/能教别人

### 第 4 步：记录快照 + 生成报告
把本次评分作为一条**历史快照**写入数据源，再跑脚本一键生成评分表 / HTML 报告 / 趋势 CSV：

1. 读取 `docs/能力评估数据.json`（单一真相源）
2. 在 `snapshots` 数组**末尾追加**一条：
   ```json
   {
     "date": "2026-07-03",
     "source": "skill-test",
     "scope": "前端",
     "note": "前端二测：JS=60、TS=40、Vue3=60…（一句话总结）",
     "scores": {
       "frontend.js": { "score": 60, "note": "薄弱点：…" },
       "frontend.ts": { "score": 40, "note": "…" }
     }
   }
   ```
   - key 必须用 **`维度id.技能id`**（维度 id：`frontend` / `backend` / `ai` / `architecture` / `python` / `management`；技能 id 见数据文件 `dimensions`）
   - `note` 写薄弱点（供 `/study` 补强），**只写本次测过的技能**
   - `source` 固定 `skill-test`，`scope` 写方向名或技能名
3. 运行 `node scripts/gen-skill-report.mjs` —— 自动重算小计 / 总分 / 岗位匹配，刷新 `个人能力评分表.md` + `能力评估报告.html` + `能力评估趋势.csv`
4. 告诉用户报告路径，提示「浏览器打开 `docs/能力评估报告.html` 看雷达图和进步趋势」
5. ⚠️ **强制：错题归档到 `docs/错题本.md`**（参见下方"错题归档强制规则"，违反 = 流程漏洞，2026-07-07 之前曾导致 4 次评估 24 条错题漏归档）

> **不要手动改 `个人能力评分表.md`**——它是脚本生成的。所有评分只通过追加 snapshot 落地。

**每次 `/skill-test` 完成后，所有 score ≤ 40 的技能涉及的错题必须归档到 `docs/错题本.md`，禁止只写在每日日志/学习记录里。**

## 评分纪律（严格口径）
- **从严评分**：遵循 `能力评估数据.json` 的 `meta.scoringPolicy`——自评应略低于真实水平，留一档安全边际；有疑虑取低档
- note 含"根本错误/说反/对调/未系统学/概念混淆"等硬伤 → 强制 ≤40；"能用/理解到位"但有关键点待巩固 → 不超过 60
- 基于真实作答评分，**不打人情分**
- 测不出水平的给 0-20，能答出原理的给 40-60，能讲清楚还能教别人的给 80-100
- 备注栏记录薄弱点，供 `/study` 后续补强
