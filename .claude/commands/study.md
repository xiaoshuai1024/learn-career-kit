# /study 系统化学习命令

你正在执行 `/study` 系统化学习流程。用户传入参数：`$ARGUMENTS`

## 用户背景
- 面向个人目标岗位（示例：前端/全栈 + AI 应用工程化，可在 `docs/能力评估数据.json` 的 jobs 中自定义）
- 能力评分表：`docs/个人能力评分表.md`
- 学习日志：`docs/每日学习日志.md`
- 学习记录（已学总览）：`docs/学习记录.md`
- 学习清单（待学）：`docs/技术学习清单.md`
- **首次使用**：若 `docs/生词本.md` 等工作文件不存在，先从 `docs/templates/` 复制同名文件到 `docs/`
- **学习前先 Read `docs/学习记录.md`**：避免重复学已掌握的、接续上次薄弱点

## 参数路由

根据 `$ARGUMENTS` 选择模式：

### 模式 A：`$ARGUMENTS` 为空 —— 自动选题
1. 读取 `docs/个人能力评分表.md`，找出评分 0 或 20（待评估/不了解）的技能
2. 优先选这些薄弱项作为本次学习主题
3. 向用户确认选题（"本次学习主题：XXX，是否开始？"），用户确认后进入【学习流程】

### 模式 B：`$ARGUMENTS` 是具体主题（如 "MCP协议"、"React原理"）
直接以该主题进入【学习流程】

### 模式 C：`$ARGUMENTS` = `review` —— 间隔重复
1. 读取 `docs/每日学习日志.md` 和 `docs/技术学习清单.md`
2. 找出最近学过但未复习的知识点（按遗忘曲线：1 天 / 3 天 / 7 天）
3. 列出待复习项，进入简化流程（重点检测，不重新讲材料）

### 模式 D：`$ARGUMENTS` = `log` —— 查看历史
1. 读取 `docs/每日学习日志.md`
2. 汇总输出：学习次数、覆盖主题、测验通过率、面试平均分、连续天数
3. 不进入学习流程

### 模式 E：`$ARGUMENTS` = `项目` —— 实战项目串联
1. 从 `docs/技术学习清单.md` 选一个实战项目（如 "FastAPI+Vue3+LangChain 全栈"）
2. 从该项目角度串联多个知识点，讲解项目如何用到这些技能
3. 进入【学习流程】

## 学习流程（模式 A / B / E 使用）

### 第 0 步：生词检查（每次学习开始前）
1. 读取 `docs/生词本.md`，统计状态为 🔴 未了解 / 🟡 了解中 的术语
2. 若存在这类术语，**主动询问用户**：「本次学习前，还有 N 个生词没确认掌握：[列表]。需要先解释一下吗？」
3. 用户需要 → 用生词本里的详细解释讲解（或重新讲解），讲完询问是否已掌握
4. 用户确认掌握 → 把该术语状态改为 🟢 已熟悉
5. 用户不需要 / 暂不处理 → 跳过，进入第 1 步（下次 `/study` 仍会提醒）

### 第 1 步：完整学习材料
针对主题输出结构化学习材料：
- 核心概念（是什么、为什么）
- 关键原理（怎么工作）
- 代码示例（可运行、标注来源）
- 常见面试考点
- 与相邻技术的对比（如适用）
- 实际工程中的应用场景

材料长度适中，重点突出，避免空洞。

> 学习记录（第 1 步即写）：输出完材料后，**立刻**在 `docs/学习记录.md` 的"已学内容详情"追加一条，状态标 🟠 学习中（评分留空、薄弱点写"待检测"、下一步留空）。这样即使中途退出，本次学了什么也有据可查。

> 术语收录：输出材料时识别本主题出现的**专业术语**。对用户可能不熟悉的术语**当场简短解释**，并追加到 `docs/生词本.md`（状态默认 🔴 未了解）；若与生词本已收录术语强相关，提示用户可顺便复习。

### 第 2 步：知识检测（5-8 题）
出 5-8 道检测题，覆盖：
- 2-3 道概念理解题
- 2-3 道原理分析题
- 1-2 道代码/应用题

逐题让用户作答，用户答完后给出每题评分和讲解，**指出错误和薄弱点**。

### 第 3 步：模拟面试（3-5 轮）
以面试官身份进行 3-5 轮追问：
- 从基础题开始，逐步深入
- 根据用户回答追问"为什么""还有别的方式吗""生产环境怎么处理"
- 模拟真实面试的连环追问节奏
- 每轮后给出表现评价

### 第 4 步：自动更新文档
学习完成后，**必须更新**以下五个文件（更新前先 Read 最新内容，保持原有格式）：
1. `docs/能力评估数据.json` —— 把本次检测/面试涉及的技能评分作为**一条快照**追加到 `snapshots`（`source="study"`，key 用 `维度id.技能id` 如 `frontend.mcp`，`note` 写薄弱点，**只写本次涉及的技能**），再运行 `node scripts/gen-skill-report.mjs` 自动刷新评分表 / HTML 报告 / 趋势 CSV。**不要手改 `个人能力评分表.md`**（脚本生成的）
2. `docs/每日学习日志.md` —— 追加本次学习记录（主题、测验结果、面试表现）；更新顶部"学习统计"表
3. `docs/技术学习清单.md` —— 若学习了清单中的项目，更新其状态为"学习中/已完成"，并在底部"学习日志"追加一行
4. `docs/生词本.md` —— 把本次新收录的术语补进"生词总览"表并附详细解释；把用户已确认掌握的术语状态改为 🟢；🟡 / 🔴 术语保留，下次 `/study` 第 0 步继续提醒
5. `docs/学习记录.md` —— 把第 1 步追加的那条更新为最终状态：🟠→🟡/🟢、补上评分与技能 key（如 `backend.concurrency`）、写明薄弱点与下一步；同步顶部"进度总览"表数字

## 信息真实性原则
- 学习材料必须准确，不确定的明确标注"待验证"
- 评分基于本次真实表现，不虚高
- 禁止编造经历或数据
